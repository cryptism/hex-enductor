# Roadmap

Feature titles only, grouped for readability — none of these are scoped or estimated yet. See `PLAN.md` for the architecture these would sit on top of.

## Navigation & structure

- [ ] Map stitching — link maps to each other at shared borders
- [ ] Click-through to sub-maps — a location with its own map shows a link that opens that map in the current editing/viewing context
- [ ] Browse and search across the whole project graph (all maps, all locations, as one navigable structure)

## Live play & presentation

- [ ] Presentation view — read-only display for a second monitor, driven by GM commands (switch map, open a location dialog, etc.) over a live channel
- [ ] Fog of war — GM can apply and selectively remove fog on a map in the Presentation view, persisted per map
- [ ] Hide individual locations from the Presentation view
- [ ] Ping a location — animate/highlight it on the Presentation view to draw the party's attention

## Location model

- [ ] Generalize "locations" beyond settlements — any point of interest (an NPC, a chest, a trap) should be a location
- [ ] Fast location authoring for the GM — icon search, form templates for common location types

## Lesser priority

- [ ] Tabs
- [ ] Player and monster counters
- [ ] Areas of effect
- [ ] Multiplayer view / online play
- [ ] Handouts
- [ ] Random generation — names, encounters
